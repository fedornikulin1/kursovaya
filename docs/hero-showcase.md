# Главный баннер: фотографии, буквы и лента

Баннер реализован в Django Templates, CSS и обычном JavaScript. Новые зависимости,
React и WebGL не требуются. Данные берутся из опубликованных объявлений; фотографии
загружаются с того же сервера, что и остальные изображения сайта.

## Файлы

- `templates/components/campus_hero.html` — заголовок, ссылки, стопка фотографий,
  управление и декоративная SVG-лента.
- `templates/components/hero_tape_words.html` — один повтор текста ленты.
- `ads/static/ads/css/hero-showcase.css` — оформление, состояния стопки и адаптация.
- `ads/static/ads/js/hero-showcase.js` — автосмена, пауза, жесты и эффект букв.
- `ads/selectors.py:hero_picks` — до шести объявлений с разными обложками.
  Сначала выбирается по одному объявлению из разных категорий, затем подборка
  дополняется. Просматриваются максимум 80 последних активных объявлений.

## Поведение

Передняя фотография является ссылкой на объявление. На ней показаны настоящие
название, категория, место и цена. Соседние снимки выглядывают сзади; при смене
они переходят в новое положение через CSS transform. Интервал автосмены — 5,5 с,
его показывает тонкая полоса под управлением. Стрелки и точки работают независимо
от автоматического режима. На сенсорных устройствах предусмотрено горизонтальное
перелистывание; вертикальный жест остаётся прокруткой страницы.

Наведение, фокус клавиатуры и прикосновение приостанавливают автоматическую смену
фотографий. Кнопка «Пауза анимаций» останавливает весь баннер: подборку, перебор букв
и движение ленты. Когда баннер уходит за экран или вкладка скрывается, движение
также приостанавливается. Учтены восстановление страницы кнопкой «Назад», системная
настройка `prefers-reduced-motion` и настройка уменьшения анимаций профиля.

Буквы состоят из коротких вертикальных полос с символами: полоса прокручивается
до нужной буквы через Web Animations API. Размер каждой ячейки определяется
итоговым символом, чтобы строка не прыгала во время перебора. Первая строка
собирается один раз; вторая меняет фразы каждые 6,5 с. Декоративные символы скрыты
от скринридера; у заголовка есть постоянное доступное название.

Лента — SVG-путь с градиентной обводкой, светлым краем и текстом `textPath`.
SMIL плавно меняет изгиб пути и положение текста. Расстояние прокрутки равно
ширине одного повторяющегося фрагмента, измеренной после загрузки шрифта.
В JavaScript нет постоянного цикла перерисовки. Без JavaScript остаются статичный
заголовок, лента и доступная ссылка на первую находку. Фоновые карточки исключены
из порядка фокуса и дерева доступности.

## Визуальные ориентиры

За основу идеи взяты публичные описания и предпросмотры
[Glyph Lottery](https://pro.reactbits.dev/docs/components/glyph-lottery?browse=components)
и [Ribbon Type](https://pro.reactbits.dev/docs/components/ribbon-type?browse=components).
Это самостоятельная реализация похожих эффектов, не подключение или перенос
компонентов React Bits Pro. Платные исходники не использовались. SVG-лента создаёт
эффект изгиба и атласного блеска, но не является трёхмерной WebGL-сценой оригинала.
Лицензия ранее использованных свободных Micro-компонентов описана отдельно
в `docs/third-party/react-bits.md` и не относится к этому новому коду.
